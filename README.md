# IRONCLAD

The initial version of this firmware patch and web installer was generated by OpenAI's **gpt-6.1-sol** from a single prompt, in about **37 minutes**, as an experiment for a **Gonzo's Machine Shop** video. During that initial build, the human author made no detailed design or implementation decisions, gave no feedback, did not review the code, and tested nothing beyond confirming that it boots and makes sound. It is not supported and will not be updated.

This repository contains the later **1.1** source, not just that initial result. The author subsequently reported an installer problem and requested a more overtly metal visual design and another sound pass. Those follow-up prompts affected the archived version. The initial build ran from approximately 04:01 to 04:38 UTC on 14 October 2026; the 1.1 work finished at approximately 05:24 UTC. Calling this entire version a single-prompt build would be inaccurate. “Patch” here means modifications to replacement-firmware source; this is not a patcher for M-VAVE's stock binary.

## The initial prompt, verbatim

```text
Connected to this computer is an MWAVE FM-1 Synthesizer. I want you to
create a patch for the existing firmware of this synth as well as a webapp
to load that firmware. Make this "the ultimate metal synth". Interpret
that in whatever way you want, no feedback from me is needed. Break out
agents for smaller tasks when it will improve speed. Build this as quickly
as possible. Here is a repo containing various firmwares as well as
documentation on reverse engineering.
https://github.com/aroum/fm1-custom-fw
```

## What gpt-6.1-sol decided “metal” means

This is my interpretation as the model that made the implementation decisions, not the author's design specification. I interpreted “metal” as a set of synthesis and interface choices: short retriggered envelopes, distortion followed by filtering, low-register note patterns, high-ratio FM modulation, and black, bone and red graphics. I treated “ultimate” as permission to choose a direction, not as a measurable claim of quality or completeness.

I chose to modify **Felucca**, an existing replacement firmware, rather than reverse-engineer and patch M-VAVE's stock synthesis code. That decision replaces the stock interface, engines, presets and data workflow. I did not establish equivalent stock features or compatibility with stock saved sounds. The 98 presets retained by this work are Felucca presets, not M-VAVE presets.

I added eleven factory presets: five ANALOG presets, five FM6 presets and one DRUM kit. The five FM6 presets use authored six-operator voices with separate carrier/modulator ratios, envelopes and velocity settings; their packed table occupies 640 bytes of flash. I added CHUG, GALLOP, SHRED, DOOM and BLAST phrase patterns, and selected IRON CHUG, RUST BASS, SHRED FM and BLAST KIT as fresh-session defaults at 160 BPM. These choices describe programmed parameters and note patterns; they do not establish how the instrument sounds.

I added a per-track METAL insert with a roughly 55 Hz pre-cut, pick emphasis, nonlinear clipping stages, cabinet-style low-pass filtering, DC removal and a gate. I reused spare effect-state fields instead of allocating another delay buffer. This adds processing per sample. I did not measure its worst-case CPU headroom on the FM-1. I retained the inherited four tracks, eight shared voices and engine-specific limits; I did not increase polyphony.

For the later visual revision, I drew a horned skull and angular IRONCLAD wordmark in C, changed cards and panels to cut-corner shapes, and made all eleven built-in palettes dark. I replaced the upstream splash, promotional QR and ordinary display branding. I changed the light PAPER theme and made old built-in palette selections migrate once to IRONCLAD. Custom palettes retain their own path. I extended the splash delay from about 0.4 to 1.2 seconds, with watchdog servicing during that delay.

I retained Felucca's synthesis engines, sequencer, storage paths and other insert choices. The upstream default already replaced its retired four-operator DIGITAL mode with FM6 conversion; that was not an IRONCLAD removal. The replacement firmware does not enable the hardware's Bluetooth/Wi-Fi radio. Battery readout code remains, but I did not establish equivalent stock battery or power behaviour. I do not know every stock feature or behaviour traded away by choosing replacement firmware.

The last build reported 55,300 of 73,728 bytes for static RAM and 328,896 of 368,640 bytes for its fixed pool. Those are build figures, not measurements of worst-case runtime safety. Original inherited source and licence notices remain in `felucca/`.

## What was and wasn't tested

- **Human hardware check:** the author reports that the installed firmware boots and makes sound. The exact version, installation procedure, notes, audio connection, duration and settings of that check were not recorded. This is not a functional test or code review.
- **Agent hardware check:** before custom installation, a read-only USB MIDI identity query identified the connected device as stock `FM-1_015`. The agents did not flash or physically audition the custom firmware.
- **Host checks:** the agents ran target compilation and size checks, C drawing/layout tests, DSP renders, simulated storage/USB/update tests, and JavaScript loader tests. The 1.1 records report 233 UI scenarios across eleven palettes, 109 preset regression renders and 33 loader/integration tests. These are computer tests with stubs or simulations, not evidence of hardware reliability. Historical records are preserved in [sessions/](sessions/README.md).

The following physical-device behaviour is **unknown**: full polyphony and worst-case load; saving and reloading projects, presets or edited FM voices; external MIDI gear and clock; USB audio; Bluetooth; battery, charging, sleep and power management; interrupted flashing; and recovery to stock. Bluetooth is disabled by the replacement's design, and no radio function was tested. Successful simulated save/reload or recovery tests do not resolve these hardware unknowns. Long-term stability, audio quality and compatibility with stock data were not established.

## Not distributed on purpose

This archive has **no releases, no prebuilt binaries and no hosted installer**. That is deliberate: the code is public so it can be read, not so it can be flashed. Installer source is included in `installer/`, but no installer is deployed and we are not going to deploy it.

An installer was hosted during development. It and its downloads were withdrawn before preparing this archive; only a withdrawal notice remains at the former address. Historical session records describe the earlier state and are not current installation instructions. Build commands exist in [BUILDING.md](BUILDING.md) to document the source and its dependencies, not to recommend installing it.

## If you flash this anyway

You do it entirely at your own risk. The device may not recover to stock. The author cannot help you. Read the [FM-1 Transporter recovery notes](https://github.com/kurogedelic/FM-1-transporter) first, and have a backup of **your own** stock firmware and saved data. Neither a recovery file nor those notes guarantee recovery.
