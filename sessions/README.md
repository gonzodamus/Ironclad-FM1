No full chat transcript was present in this working directory; none is invented or substituted for one. The separate agent session store was consulted only to identify model and timestamps.

These historical records can contain superseded instructions, old paths, firmware hashes, claims of tests and references to the former installer. They are not current instructions or proof of physical-device validation. Historical references are preserved because the records must not be edited; active source and documentation contain no former installer address. The current README corrects the single-prompt and hardware-validation scope.
